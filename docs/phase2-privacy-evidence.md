# Phase 2 privacy evidence — each fixed rule, its code and its tests

[ADR 0001](adr/0001-phase2-data-access.md) fixes six rules for every later sprint. This page
traces each one to the code that enforces it and to the tests that would fail if it were
broken, so a reviewer can check the claim instead of taking it. The rules themselves are
quoted from the ADR; the wording of a rule is not changed here.

Every test name below was grepped in this repository, so each one exists and is named
exactly as the runner prints it. Line numbers are the ones at the time of writing; the
function or constant in the same cell is what to search for when a line has moved.

| # | Rule (ADR 0001) | Enforced by | Proven by |
| :-- | :--- | :--- | :--- |
| 1 | KSU passwords are never collected, stored or transmitted by KSU Agent. | Every read is a same-origin GET in the student's own session: `extension/src/content/edugate.ts:253` and `extension/src/lms/session.ts:64` (`credentials: "same-origin"`). The manifest has no `cookies` permission, so even the session cookie cannot be read: `extension/manifest.json:5` (`"permissions": ["storage"]`). `/chat` accepts `message` and `session_id` and no other field: `backend/app/main.py:121` (`ChatRequest`). | `extension/test/background.test.ts::keeps only the fields the contract lists` — a `password` key a page happens to expose is dropped before it leaves the extension.<br>`extension/test/content.test.ts::follows the final exams forward stub with one POST and reads the page behind it` — the read carries `credentials: "same-origin"`, not a stored credential.<br>`extension/test/content/lms.test.ts::reads the course list in the student's own session` — the same for the LMS. |

## How to re-run the evidence

```bash
# rules 1, 2 and 5 — the backend half
cd backend && python -m pytest tests/test_privacy_audit.py tests/test_with_data.py -q

# rules 1, 2 and 4 — the extension half
cd extension && npm test

# rule 2 — the website half
cd frontend && npx vitest run src/components/chat/ChatScreen.test.tsx
```
